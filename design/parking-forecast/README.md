## 结论摘要

1. **停车预测模块放独立目录 `parking-forecast/`**（仓库根目录，与 `changdi-intake/` 平级），不并入 `changdi-intake`。理由见 01 文档「模块放置位置」。
2. **运行时与训练分离**：Python（numpy/pandas/sklearn 已在本机可用）负责合成数据、训练、回测与产物导出；产物是版本化 JSON，运行时用零依赖 Node/浏览器脚本读取，页面不引入构建步骤。
3. **导览侧事件复用现有 tourism 通路**，不新增事件类型、不改 `changdi-intake` 迁移。本任务对 `changdi-intake` 的改动边界为「零」；新增事件类型与新增车场目录代码需要另开任务并动迁移。
4. **合成数据只验证管道，不构成正式达标**。≤20% 预测误差目标只有真实历史数据 + 现场校验才能确立。
