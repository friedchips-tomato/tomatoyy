# 长堤像素导览 · 视觉风格规范

## 一句话
**淡彩像素、干净方块、轻轻浮起。** 像把一块手工像素画片放在浅米色桌面上。

## 像素
- 全图一种像素格尺寸，不允许大小格混用。
- 曲线（拱券、穹顶、树冠、船身）一律画成横竖台阶，不能出现平滑曲线。
- 不描黑色外轮廓。形体靠颜色深浅和前后遮挡区分。
- 细节归成成组的小矩形，不追求照片级细节。

## 颜色
| 用途 | 颜色 |
|---|---|
| 底色（留白） | 米白 `#f6f2ec`，低饱和 |
| 大面积浅色 | 米白、浅杏黄、淡粉、浅灰绿、浅青绿（江水） |
| 少量深色 | 深灰绿（树冠暗部）、深棕（门窗）、灰蓝（瓦顶） |
| 唯一亮点 | 每张图只允许一处鲜明色，例如一串红灯笼 |

## 质感
- 色块干净平整：不加颗粒、噪点、做旧纸纹。
- 不做厚重 3D 挤出，不做塑料高光。
- 唯一的柔化是右下方的淡投影，由近到远逐渐消失。

## 构图
- **地图**：整条街区是一块边缘整齐的像素画片，四周留窄边，右下有淡投影。竖放：江在右侧，街从上往下排。
- **卡片**：一块小的像素画片居中悬浮，四周留大片空白，右下有淡投影；画片不能撑满画面，也不能被裁切。
- 地图上不出现任何文字，名称由程序叠加。卡片可在画片下方放一行细体无衬线说明，内容必须是这个地点的具体事物。

## 验收清单
- [ ] 像素格大小统一，放大 3 倍边缘仍是方的
- [ ] 没有黑描边、没有光滑曲线
- [ ] 只有一个鲜明色亮点
- [ ] 地图无文字；卡片说明文字无错字
- [ ] 建筑特征与参考照片对得上（拱券数、层数、窗型、颜色）
- [ ] 右下投影是淡的，没有变成黑框
