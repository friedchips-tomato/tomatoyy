# 建筑像素卡片 · 提示词模板

把 `{…}` 换成具体内容。有现场照片时，把照片作为参考图一起发给 GPT，并删掉「没有照片」那一句。

```
画一张 3:4 竖版的建筑像素卡片。

【主体】{建筑或场景的描述：层数、开间、拱券数、窗型、立面颜色、屋顶装饰、门口的物件}
（没有照片时）以上文字就是全部依据，不要添加描述里没有的建筑构件。
（有照片时）严格按参考照片的比例和立面特征画，只简化细节，不改结构。

【构图】只画主体和一点点脚下的地面，删掉其余环境。主体做成一块边缘整齐的小像素画片，放在画面中央偏上，大约占画面宽度的 55%，四周留大片米白色空白。画片右下方有一道很淡的柔和投影，由近到远逐渐消失，不能变成黑框。

【画法】全图统一像素格大小。所有曲线画成横竖台阶，细节归成小矩形。不描黑边，靠颜色深浅和遮挡区分前后。色块干净平整，不加颗粒、噪点、做旧纸纹，不做 3D 挤出和塑料高光。

【颜色】以米白、浅杏黄、淡粉、浅灰绿等高明度淡彩为主，用少量深棕、深灰绿压住重心，只有 {唯一亮点，例如一串红灯笼} 一处鲜明颜色。背景为低饱和米白。

【文字】在画片下方留出空隙，用细体无衬线字写一行：「{地点 · 具体事物}」。除此之外不出现任何文字。
```
