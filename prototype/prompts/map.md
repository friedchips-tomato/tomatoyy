```
竖版 2:3 像素地图插画，3/4 斜俯视角度，一张中国广东江门「长堤」历史街区的示意导览地图。

【布局，必须遵守】
- 画面右侧约三分之一是一条从画面顶端贯通到底端的宽阔河流，浅青绿色水面，用横向阶梯色带表现水纹。
- 河流左岸是一条从上到下的沿江马路（浅灰色），马路左侧紧贴着一整排连续的两到三层岭南骑楼：底层是连续拱券柱廊（骑楼走廊），上层有竖长窗和彩色满洲窗，屋顶边缘有弧形或阶梯形山花女儿墙；立面颜色米白、浅杏黄、淡粉、浅灰绿交替。
- 骑楼排后面（画面左侧）是更低矮的旧民居灰瓦屋顶和窄巷。
- 画面最上端一座混凝土公路桥横跨河流；画面最下端一座钢桁架铁桥横跨河流。
- 沿街从上到下依次留出这些清晰可辨、彼此分开的地标：
  1. 上部、画面左侧内陆：一片青砖小巷村落，巷口有一座小门楼；
  2. 上中部、沿江路边：一座较大的西式两层建筑，带连续拱廊和一个小钟楼，前面有一块小广场；
  3. 正中部、沿江路边：一座双联骑楼（两栋并排一样的骑楼），门口有户外咖啡桌和遮阳伞；
  4. 中部、河岸边：一段从岸上一级级下降到水面的长石阶码头，石阶旁停一艘小木船；
  5. 中下部：一条垂直于沿江路、向画面左侧内陆延伸的老街，两侧也是骑楼；
  6. 下部、画面左侧：一条更窄的老墟街，街上有几个小摊棚；
  7. 下部、河边：一个小停车场，停着几辆小汽车。
- 街上零星有小人行走，有几棵大榕树。
- 画面中不得出现任何文字、字母、数字、招牌字、地图图例或标注。

【画法】造型以统一像素格与阶梯轮廓为核心：曲线拆成短促的横竖台阶，细节归并为成组矩形，深度靠色带宽窄、递减尺度与遮挡表现。全图像素格大小统一。不描黑边，不逐点追摹写实细节。材质为干净色块：干净平整，不做颗粒和做旧，像素边缘清楚，不抹糊，不添加厚重立体挤出。

【配色】高明度淡彩为主（米白、浅杏、淡粉、浅青绿、浅灰蓝），少量沉稳深色（深灰绿树冠、深棕门窗）压住重心，只有一处略鲜明的小色块（骑楼下一串红灯笼）作为唯一亮点。

【整体】整个街区是一块边缘整齐的完整像素画片，悬置在浅色、低饱和的留白底上，四周只留很窄的边距，右下方有由近及远淡出的柔和投影。清淡、轻盈、略带怀旧感。避免卡通感、塑料光泽、厚重立体挤出、旧纸纹理、像素格大小混乱、光滑曲线。
```
