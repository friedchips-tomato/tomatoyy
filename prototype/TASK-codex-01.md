# Codex 任务书 01 · 长堤像素导览 H5 演示版

你负责写代码。文字和数据由 Claude 提供，**不要改写 `data/points.js` 里的任何文字**，也不要在代码里写死史实内容；界面上的按钮、提示等短文案可以写在代码里。

## 目标
在 `prototype/` 下做一个**纯静态、无构建步骤**的竖屏手机网页，模拟微信小程序的效果，用手机浏览器打开就能点。后续会移植成原生微信小程序，所以结构保持简单：一个页面 + 若干弹层，状态集中在一个 `state` 对象里。

## 文件
- `index.html`、`styles.css`、`app.js`：你来写。
- `data/points.js`：已存在，`window.CD_DATA`，**只读**。字段含义见文件注释。
- `assets/map.jpg`：竖版像素地图（约 1365×2048）。`assets/card-*.jpg`：建筑像素卡片（3:4）。这些图稍后才会出现，代码按路径引用即可；卡片为 `null` 时用地图上该点位的局部作为缩略图（用 background-position 截取 hotspot 区域）。
- 只用原生 HTML/CSS/JS，不引任何 CDN 和框架；`file://` 直接打开也必须能运行（所以数据用 `<script src="data/points.js">`，不用 fetch）。

## 布局（竖屏，宽 ≤ 430px 时全屏；更宽的屏幕上居中显示一个 390×844 的手机框）
1. **顶栏**（固定）：标题「长堤风貌街」+ 小字副标题；右侧讲解语言切换 `普 / 粤 / EN`；第二行「已点亮 n / 总数」进度条（只统计 `key: true` 的点位）。
2. **地图区**（占满中间）：`assets/map.jpg` 宽度铺满、可上下滚动。底图默认**灰度**（`filter: grayscale(1) contrast(.95) brightness(1.06)`）。已点亮的点位在其 hotspot 区域上叠一层彩色原图（同一张图用 background-size/position 精确对齐），点亮时 0.8s 由透明渐显，并伴随轻微缩放弹跳。
   - 每个点位按 `hotspot`（百分比）放一个透明可点区域；可点区域上方放一个小的像素风名称牌（白底、1px 深色边、`image-rendering: pixelated` 风格的方角），未点亮的显示灰色，已点亮显示彩色。
   - 右下角浮动按钮：放大 / 缩小（三档：100% / 150% / 200%，`image-rendering: pixelated`，缩放后保持当前视口中心）。
   - 地图底部显示 `meta.disclaimer` 小字。
3. **迷你播放条**：讲解播放时出现在底部按钮栏上方，显示「正在讲解：xxx」、暂停/继续、关闭。
4. **底部按钮栏**（固定 4 个）：路线、扫码、服务、我的。每个打开一个**底部弹层**（bottom sheet，圆角 16px，可下滑或点遮罩关闭），不跳页。

## 交互
- **点地图点位** → 底部弹出点位卡：卡片图（3:4，宽约 40%）+ 名称 + 类别 + `oneLine`；按钮「听讲解」「打卡」「详情」，非停车点位才有讲解。停车点位（`parking` 字段）直接显示停车信息（同「服务 → 停车」里的单项）。
- **听讲解**：用 `speechSynthesis` 朗读 `guide[lang]`，lang 对应 `zh-CN` / `zh-HK` / `en-US`，选该语言可用的声音；不支持时显示文字并提示。播放时迷你播放条出现；讲解卡里同时显示讲解文字，正在读的句子高亮（按句号/问号切句，`onboundary` 不可靠时按时间估算即可）。
- **打卡**：点亮该点位（彩色渐显），弹出「获得电子小卡」动画：卡片从建筑位置飞到屏幕中央、翻面显示卡图和 `cardName`，点任意处收起。状态写 localStorage（key `cd-demo-v1`）。已打卡的按钮显示「已点亮」。
- **详情**：弹层拉到全屏：大图、`intro`、所属故事线（若该点位在 `stories` 的 nodes 里，显示故事线名称和本节文字，点「看故事线」）、`sources` 列表（标题「资料来源」，小字）、按钮「预约讲解员」「附近停车」。
- **看故事线**：关闭弹层，地图上用像素风虚线（SVG，`stroke-dasharray`，方角线帽）按顺序连接各节点 hotspot 中心，节点上显示序号；顶部出现故事线横条，可左右切换节点，切换时地图平滑滚动到该点并显示该节 `text`；有「退出故事线」按钮。
- **路线**弹层：三步——①兴趣多选（`interests`）②时长 30/60/120 分钟 ③出行方式 步行/自驾。点「生成路线」后显示 0.8s 加载骨架，然后列出 `routes` 三张卡（自驾时 `drive: true` 的排第一，否则按 tags 与所选兴趣的重合数排序），卡上显示名称、时长、距离、点位数、`reason`；地图上同时用三种 `color` 的虚线预览三条路线。点「采纳」→ 只保留该路线，顶部出现「下一站：xxx · 第 i/n 站」条，带「到了」按钮（模拟到达：滚动到该点、自动打卡并开始讲解，然后跳下一站），全部完成后弹出完成提示。
- **扫码**弹层：说明「演示版：选择一个点位模拟扫码 / NFC」，列出所有 `key: true` 的点位；点一项 → 关闭弹层、地图平滑滚动到该点并闪烁、自动打卡。
- **服务**弹层：三个分页签
  - 讲解员：列表来自 `guides`，顶部黄色标签「示范数据」；筛选语种；点某人 → 选时段 + 人数 → 提交 → 显示「已提交，待讲解员确认（目标 30 分钟内）」，记入「我的预约」。
  - 停车：来自 `parking`，「示范数据」标签；每项显示余位/总数、余位条（>30% 绿、10–30% 黄、<10% 红）、步行距离、收费、更新时间、`reason`，以及一个小折线图（SVG）：`past` 实线 + `forecast` 虚线（未来 1 小时）。按钮「设为路线起点」→ 关闭弹层并打开路线弹层，出行方式预选自驾。
  - 反馈：类型（`feedbackTypes`）、描述、可选图片（只做本地预览）、联系方式（下方小字「仅授权处理人员可见」）；提交后生成编号 `CD-yyyyMMdd-xxxx` 和状态时间线（已受理 ●→ 分派 ○→ 处理中 ○→ 待评价 ○），记入「我的诉求」。
- **我的**弹层：点亮进度；电子卡册网格（所有 `key: true` 点位，未获得的显示灰色剪影 + 「?」，获得的显示卡图）；我的预约；我的诉求；「重置演示」按钮清空 localStorage。

## 视觉
- 整体是**淡彩像素风**，和地图、卡片一致：底色 `#f6f2ec`，主文字 `#3b3a36`，强调色取一种柔和的砖红 `#d0634b`，辅助青绿 `#5f9ea0`。
- 按钮、弹层、名称牌用**方角或 4px 小圆角 + 2px 偏移硬阴影**（`box-shadow: 2px 2px 0 rgba(59,58,54,.25)`），营造像素 UI 感；不要渐变、不要毛玻璃。
- 字体：系统无衬线（`-apple-system, "PingFang SC", sans-serif`），标题可加 `letter-spacing: .05em`。
- 适配刘海和底部安全区（`env(safe-area-inset-*)`），所有可点区域 ≥ 44px。
