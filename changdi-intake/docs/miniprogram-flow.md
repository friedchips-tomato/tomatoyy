# 长堤风貌街接诉即办小程序页面流与动作矩阵

依据 [实施验收清单](./implementation-checklist.md)。页面编号供实现与验收引用。页面可用列表、详情和表单组件复用，表中字段为首版所需信息，带「选填」的输入可留空。详情、列表和动作均按服务端返回的身份、归属及状态展示。

## 实现环境

| 标记 | 首版工作与验证方式 |
| --- | --- |
| 本地 | 用模拟回执、测试身份、工单和图片验证页面跳转、字段、角色、状态、失败恢复。直接传入测试公开码模拟扫码。页面流包含后续待实现能力，验收时按实际接通项勾记。 |
| 微信 | 用已配置的微信小程序账号和体验版，在真机验证扫码落页、身份核验、照片选择与预览。订阅模板可用且用户授权时验证反馈通知。 |
| 平台 | 外部平台制作和运营申报表单、提交附件、续取及展示回执。正式接入需要双方配置 HTTPS 环境，并完成从实际表单回执扫码到小程序的联合验收。 |
| 试点 | 用实际账号、部门、商户、人员、字段公开规则、时限和升级配置验证。正式域名、项目存储和发布流程按验收清单核对。 |

## 一、主流程与页面布局

~~~text
外部平台 X01 申报 → X02 回执 → 扫小程序码 → T02 公开进度
H01 首页
  游客与居民 → T01 我的诉求（本机回执夹）→ 扫码或查看到 T02 → T03 本人核验 → T04
  提交诉求 → T08 提交诉求 → 回执（公开查询码）→ T02 公开进度
  商户 → B01 身份核验 → B02 商户工单 / B03 提交 / B05 协办待办
  管理方 → A01 身份核验 → A02 工作台 → A03 工单列表 → A04 工单详情
T02 公开进度 → T03 本人核验 → T04 本人详情
  待补充材料 → T05 补材料 → T04 已提交
  待评价 → T06 评价 → T04 可确认解决
  待评价或已办结 → T07 申请补办 → T04 补办待审核
A04 工单详情 → A05 受理处置 / A06 分派转派及协办 / A07 现场承办
  已提交 → 已受理 → 已分派 → 处理中 → 待复核
  商户协办 B05 → B06 交说明及照片 → A08 复核
  承办结果送审 → A08 复核发布 → 待评价 → 已办结
  补办待审核 → A09 审核补办 → 已分派或处理中（原编号，新一轮）
~~~

| 页 | 入口与最少显示 | 按钮、允许角色及成功去向 | 空态与失败反馈 |
| --- | --- | --- | --- |
| H01 首页 · 本地／微信 | 小程序启动、各窗口返回。仅列「提交诉求」「游客与居民」「商户」「管理方」四个入口。「游客与居民」进入本机回执夹，做我的诉求与进度查询。底部提示：提交后回执可在本机「我的诉求」查看，也可扫码或输码查询。 | 「提交诉求」所有人 → T08。「游客与居民」所有人 → T01。「商户」→ B01。「管理方」→ A01。后两项进入前核验账号，任意工单状态均可导航。 | 首页资源重试时仍可操作已加载入口。身份核验异常由对应页面提示。 |
| X01 外部申报 · 本地模拟／平台 | 外部平台申报入口。发生时间、地点（可手填）、问题类别、描述必填。照片、建议部门、联系方式选填。外部申报单号由平台生成。 | 「提交」游客、居民，支持匿名。外部服务端一次提交表单和照片，收到成功回执 → X02。 | 初始显示空表单。字段或附件错误定位到输入，保留其余内容。网络中断或回执未知时提示「结果确认中」，用同一外部单号重试原请求。 |
| X02 外部回执 · 本地模拟／平台／微信 | X01 收到成功回执后进入。显示成功、工单编号、小程序二维码。另在提交人的回执会话中私下展示查询凭证及保存提示。 | 「查看进度」通过二维码进入 T02，二维码只携带公开查询码。状态随工单更新。 | 回执尚未获得时显示等待或重试状态，用原单号续取。查询码加载失败时重试回执显示，保留已成功的工单编号。 |

## 二、游客与居民窗口

~~~text
T02 公开进度                         T04 本人详情
[工单编号]                           [工单编号] [当前状态]
[当前状态]                           [当前轮次] [处理时间线]
[获准公开的时间节点列表]             [已发布反馈与可展示照片 / 当前待办]
[核验本人]                           [按状态显示的操作] [往轮记录（如有）]
~~~

| 页 | 入口与最少显示或输入 | 按钮、允许角色和状态及成功去向 | 空态与失败反馈 |
| --- | --- | --- | --- |
| T01 我的诉求 · 本地／微信 | H01。读取本机回执夹，展示其中的工单编号、当前状态与最近公开节点时间。本机只保存工单编号、公开查询码与提交时间三项，不保存问题描述、地点、联系方式与照片。 | 「扫码查询」所有人、任意状态 → T02。「查看」任意状态 → T02，网址只带公开查询码。「清除本机记录」所有人，二次确认后清除本机记录。 | 空列表提示本机只保存编号与公开码，可凭回执扫码查询；私密查询凭证不在本机保存。单条查询失败保留该条并提示可重试。扫码取消留页，无法识别提示重新扫。记录仅保存在本机，换手机或清除缓存后不再显示。 |
| T02 公开进度 · 本地／平台／微信 | X02 二维码或 T01 扫码。业务数据仅显示工单编号、当前状态、获准公开的时间节点（节点名称与时间）。 | 「核验本人」所有持有效公开码者、任意状态 → T03。 | 无公开节点时显示「暂无公开进度节点」。缺码、无效码或找不到记录时提示「无法查询，请重新扫描回执」，不回显输入值。网络失败可重试。 |
| T03 本人核验 · 本地／微信 | T02。工单编号、独立的私密凭证输入框，具备可用的原提交人身份绑定时提供身份核验入口。 | 「验证」持本单凭证者、任意状态 → T04。「用已绑定身份验证」原提交人、任意状态 → T04。 | 空凭证提示输入。错误或与本单不匹配提示「凭证有误，请核对回执」，受限提示稍后重试。成功、退出及会话失效时清空凭证。 |
| T04 本人详情 · 本地／微信 | T03 通过或 T01 有效本人权限。显示编号、状态、轮次、办理时间线、适用的补件要求、不予受理或补办审核理由、已发布完整反馈与可展示照片、评价与补办截止时间、历轮反馈及评分。 | 本人按状态使用「补充材料」→ T05、「评价」→ T06、「确认解决」→ 本页刷新、「申请补办」→ T07。详细条件见矩阵。 | 尚未发布时显示「暂无处理反馈」。照片加载失败可重试。本人授权失效时隐藏私密内容，返回 T02 并可再次进入 T03。 |
| T05 补充材料 · 本地／微信 | T04。补件要求、说明、所需照片或附件按要求录入。 | 「提交材料」本单原提交人，待补充材料 → T04，原单回到已提交。 | 空内容提示按要求补充。上传失败支持单张重试并保留其他已选内容。状态变化时刷新 T04 查看当前状态。 |
| T06 评价 · 本地／微信 | T04。当前轮处理反馈，处理速度、处理效果、服务态度各 1–5 分，意见选填。 | 「提交评价」原提交人，待评价、未过评价期且本轮无有效评价 → T04 显示已评价。 | 初始无预选分数。缺项提示对应维度；本轮已有评价时显示原记录，重复请求只认一份；已过期时回 T04。 |
| T07 申请补办 · 本地／微信 | T04。原工单编号、当前反馈、申请截止时间、未解决事项说明。 | 「提交申请」原提交人，待评价或已办结、在配置期内且无待审申请 → T04 显示补办待审核。 | 空说明定位到输入。期满显示已超过申请期。有待审申请则展示已有状态，超时先刷新确认提交结果。 |
| T08 提交诉求 · 本地／微信 | H01。发生时间（日期与时刻，默认当前北京时间）、发生地点、问题类别（选项与商户窗口同一套分类）、问题描述必填；现场照片 0–3 张、联系方式选填。匿名提交，不需身份核验。 | 「提交诉求」所有人 → 受理中，显示回执卡片：工单编号、公开查询码、私密查询凭证。「查看进度」所有人 → T02，网址只带公开查询码。「再提交一条」所有人 → 重置表单，用新的请求号开始下一次提交。 | 必填字段就地提示并保留其余输入。提交期间锁定，不接受重复提交。网络中断或超时保留表单与请求号，用同一请求重试，服务端按请求号去重，不重复建单。409 提示内容冲突并建议先查回执，429 提示稍后再试。回执中的工单编号与公开查询码另存进本机回执夹（只有编号、公开码与提交时间），可一键清除；回执中的私密凭证仅显示一次，只留在页面内存，不写存储、不进网址与日志。 |

私密查询凭证由提交人主动输入，仅用于服务端核验。二维码、页面 URL、分享链接、公开响应及日志均不能携带凭证。T08 的回执卡片由服务端直接下发私密凭证，只在页面内存中显示一次，不写存储、不进网址与日志，离开页面后无法再次查看。T02 的「核验本人」只发起导航，公开查单结果只返回允许公开的工单字段。T04 至 T07 每次请求均检查当前工单的本人授权。退回公开进度、切换工单或会话失效时，清理当前私密页面的数据。未核验时访问本人详情，先走 T02 → T03。联系方式和授权照片按相应权限读取。

## 三、商户窗口

| 页 | 入口与最少显示或输入 | 按钮、允许角色和状态及成功去向 | 空态与失败反馈 |
| --- | --- | --- | --- |
| B01 商户身份核验 · 本地／微信／试点 | H01。当前身份、核验结果、授权后显示绑定商户。 | 「核验商户身份」当前账号，商户绑定由运营人员核验 → B02。「查阅脱敏月报」有对应授权的商户代表 → A11。 | 无绑定或审批待处理时提示联系运营人员或等待核验。核验失败可重试，权限回收时回本页。 |
| B02 本商户工单 · 本地／试点 | B01 通过。编号、状态、提交时间，可按状态筛选。 | 「提交诉求」获提交权限的已核验商户 → B03。「查看」获该商户工单读取权限、任意状态 → B04。「协办待办」获协办权限 → B05。 | 分别显示「暂无本商户工单」和「暂无匹配记录」。加载失败可重试。 |
| B03 提交商户诉求 · 本地／微信／试点 | B02。绑定商户只读，发生时间、地点、问题类别、描述，照片和联系方式选填。 | 「提交诉求」获提交权限的商户成员，新建 → B04，显示编号和已提交。 | 初始空表单。必填、上传错误就地提示并保留内容；提交结果未知时先确认结果。 |
| B04 商户工单详情 · 本地／试点 | B02 或 B03 成功。编号、状态、诉求摘要、时间线、已发布反馈、本人权限适用的期限和历史。 | 「返回列表」获本商户阅读权限者，任意状态 → B02。原提交人经核验且符合矩阵时可进入 T05／T06／T07 或确认解决，成功后回 B04。 | 未反馈显示「暂无处理反馈」。授权变化时回 B01，切换到其他商户工单时提示无权限。 |
| B05 协办待办 · 本地／试点 | B02。仅列获派任务，字段为任务摘要、期限、办理状态。 | 「查看协办」获派且仍具该任务权限的商户成员 → B06。 | 无获派任务时显示「暂无协办任务」。刷新后若任务撤回，移出列表并提示任务已更新。 |
| B06 协办任务详情 · 本地／微信／试点 | B05。管理方指定的协办事项、必要地点及说明、任务期限、退回理由（如有）；录入协办说明与照片。 | 「提交协办」获派商户成员，任务待提交或退回补充且仍有效 → 本页显示待管理方复核，B05 刷新。 | 说明为空时就地提示。照片上传失败可重试。任务已撤回、已送审或失权时刷新并撤下提交按钮。 |

B06 按任务授权读取限定信息和附件。协办送审更新任务状态，工单主线仍由承办与管理方推进。

## 四、管理方窗口

| 页 | 入口与最少显示或输入 | 按钮、允许角色和状态及成功去向 | 空态与失败反馈 |
| --- | --- | --- | --- |
| A01 工作人员核验 · 本地／微信／试点 | H01。显示核验进度，成功后读取获批角色和部门。 | 「核验工作人员身份」当前账号，经审批且有效 → A02。 | 待审批提示等待，账号无权限提示联系管理方。网络异常可重试。 |
| A02 工作台 · 本地／试点 | A01。按授权展示待受理、待分派、处理中、临期、超时、待复核和补办待审核的数量。 | 「查看队列」工作人员、获授权队列 → A03。「人员与配置」配置授权人 → A10。「统计月报」月报授权人 → A11。 | 空队列标零，计数加载失败单独提示重试，避免显示为零。 |
| A03 工单列表 · 本地／试点 | A02。编号、类别、地点摘要、来源、状态、主责部门或承办人、截止时间（按权限），可按队列、状态筛选。 | 「查看」有工单范围权限的工作人员、任意状态 → A04。 | 「暂无工单」或「暂无匹配记录」，可清除筛选。加载失败保留当前筛选并重试。 |
| A04 工单详情 · 本地／试点 | A03 或操作页成功返回。编号、来源、申报字段、当前状态、当前轮次、主责人、期限、附件、协办、反馈及审计时间线按角色显示。 | 「受理处置」→ A05、「派单／转派／追加协办」→ A06、「接单／现场办理」→ A07、「复核」→ A08、「审核补办」→ A09。到期或已确认解决时，授权人可「结案」并刷新。 | 无派单、附件或历史时各自显示空态。联系方式需独立权限且审计。权限变化返回列表，工单有更新时刷新动作。 |
| A05 受理处置 · 本地／试点 | A04 的已提交工单。待核实申报要素；补材料说明或不予受理理由按动作必填。 | 授权值班人员，已提交时可「受理」→ 已受理、「要求补材料」→ 待补充材料、「不予受理」→ 不予受理，成功均回 A04。 | 尚未上传照片时显示暂无附件。理由必填时定位输入；他人已处置提示刷新。 |
| A06 分派、转派及协办 · 本地／试点 | A04。类别与地点给出建议部门，确认一个主责部门、承办人、期限；转派填原因；追加协办填协办单位或商户、必要说明和期限。 | 授权值班人员或主管，「确认分派」已受理 → 已分派；「确认转派」已分派／处理中 → 已分派，原因入历史；「追加协办」已分派／处理中 → 创建任务、原单状态保持。成功回 A04。 | 暂无建议时可在可派部门中选择。无可派承办人提示核对人员配置。并发更新时保留未提交输入并提示核对最新归属和期限。 |
| A07 现场承办 · 本地／微信／试点 | A04。分派信息、办理期限、当前轮记录；录入进度、处理说明、现场照片，无照片时填写原因。 | 「接单」当前承办人、已分派 → 本页处理中。「保存进度」当前承办人、处理中 → 本页刷新。「提交复核」当前承办人、处理中 → A04 待复核。 | 无处理中记录时显示暂无办理进度。缺说明或照片原因时就地提示，上传失败可重试。改派后刷新归属并停止提交。 |
| A08 复核与反馈 · 本地／微信／试点 | A04。处理说明、照片或缺照原因、协办材料、拟向提交人展示的说明与照片、退回原因。复查人脸、车牌和联系方式等可识别内容。 | 授权复核人对待复核的协办任务「通过」或「退回补充」，工单状态保持。原单待复核时可「退回承办」→ 处理中，或「发布反馈」→ 待评价。成功回 A04。 | 暂无协办时显示空态。缺展示说明、退回原因或复核未通过项时提示定位；发布失败时保留编辑内容。 |
| A09 补办审核 · 本地／试点 | A04 或补办队列。原编号、申请理由、申请前状态、历轮反馈和评分。批准时核对新轮承办与期限；驳回填写反馈理由。 | 授权审核人、补办待审核。「通过并分派」→ 已分派；「通过并继续办理」→ 处理中（承办归属已确认）；「驳回」→ 恢复申请前状态并留理由。成功回 A04。 | 未查到待审申请时显示「暂无待审核申请」。已被处理时刷新，申请及原办理记录可回查。 |
| A10 人员与办理配置 · 本地／试点 | A02。角色、部门、人员、商户绑定、点位、问题分类与时限规则，逐项只显示必要标识及当前配置。 | 「添加／编辑／保存」对应配置授权人，配置不依赖某工单状态，成功后留页并更新列表。 | 无记录提示先维护对应基础资料。必填、重复或无效关联定位到字段；保存失败保留编辑内容。 |
| A11 统计月报 · 本地／平台／试点 | A02 或商户代表授权入口。月份、取数日、首次响应、处理完成率、超时、重复投诉、三维满意度和未评价数，导览区显示数据来源状态。 | 「查看月报」对应范围的月报授权人，可切换月份并留页。商户代表仅查看获授权的脱敏汇总。 | 月份无样本显示暂无数据。导览来源未接入显示「导览数据缺失」。加载失败保留月份并可重试。 |

## 五、工单动作矩阵

每行动作以服务端最新状态、角色和归属作准。无权限者看不到按钮；有权限但缺必填项时就地提示；状态在操作中改变时刷新详情并说明原因。以下列出的协办状态属于任务，待复核也可作为工单办理阶段对管理方显示，公开页按许可展示节点。

| 动作 | 发起页／允许角色 | 所需状态及条件 | 成功状态与去向 |
| --- | --- | --- | --- |
| 外部申报／续取回执 | X01／外部平台服务端 | 新申报或同一接入方、原单号的同一内容重试 | 新单已提交；重试返回原单及可用回执，现有状态保持 → X02 |
| 商户申报 | B03／获授权已核验商户 | 新建 | 已提交 → B04 |
| 查看公开进度 | T02／持有效公开查询码 | 任意状态 | 留 T02，仅三类公开字段 |
| 核验后查看本人详情 | T03／本单本人 | 任意状态，正确私密凭证或已绑定身份验证通过 | 状态保持 → T04 |
| 受理／要求补材料／不予受理 | A05／授权值班人员 | 已提交；后两项填写说明 | 分别已受理／待补充材料／不予受理 → A04 |
| 补交材料 | T05／本单原提交人 | 待补充材料，满足补件要求 | 已提交，回待受理队列 → T04 或 B04 |
| 分派／转派 | A06／授权值班人员、主管 | 分派时已受理；转派时已分派或处理中，填写原因；两者均明确归属和期限 | 已分派 → A04，入新承办人队列 |
| 接单／登记现场进度／送审 | A07／当前承办人 | 接单时已分派；登记或送审时处理中，送审需说明及照片或缺照原因 | 分别处理中／处理中／待复核 |
| 追加协办／提交协办 | A06／授权值班人员、主管；B06／获派商户成员 | 指派时已分派或处理中；提交时协办任务待提交或退回补充且有效 | 任务分别待提交／待复核，当前工单状态保持 |
| 复核协办 | A08／授权复核人 | 协办任务待复核 | 任务通过或退回补充，当前工单状态保持 → A04 |
| 退回承办／发布反馈 | A08／授权复核人 | 原单待复核；退回需原因；发布需复核处理说明及可展示照片 | 处理中或待评价 → A04，发布后本人可查看 |
| 提交评价 | T06／本单原提交人 | 待评价；当前轮在评价期且无有效评价 | 待评价，记录三项评分 → T04 或 B04 |
| 确认解决／到期结案 | T04 或 B04／本单原提交人；A04 或配置的到期机制／授权管理方 | 待评价；本人确认解决，或评价期届满且满足结案规则 | 已办结；未评分的记为未评价 → 对应详情 |
| 申请补办 | T07／本单原提交人 | 待评价或已办结；在配置申请期且无待审申请 | 补办待审核 → T04 或 B04 |
| 批准／驳回补办 | A09／授权审核人 | 补办待审核；批准时确认承办归属与期限，驳回需理由 | 批准沿用原编号进入已分派或处理中并开新轮；驳回恢复申请前状态 → A04 |

低保真实现约定。将「待复核」用于承办送审后的工作台及详情，将评价与确认解决做成两个独立动作。未批准的补办回到申请前的状态，原记录保留。跨部门转派和补办均按试点确认的规则计算期限。

## 六、通用交互与走查

- 加载中显示加载状态，列表请求失败保留筛选条件。写入期间只接受一次当前操作，弱网重试前刷新结果，尤其检查外部回执、分派、评价和补办。
- 表单错误定位到相应字段并保留其他输入。上传中显示进度和已完成项，失败可按图重试。敏感凭证不进入上报、长期缓存或分享内容。
- 按钮、输入和时间线节点使用文字标签。错误反馈紧邻字段，分数和工单状态用文字显示。真机检查键盘弹出后仍能查看必填项、错误信息和提交按钮。
- 本地走查一。模拟外部匿名申报及多图回执，扫码到 T02，分别验证错凭证、限次与正确凭证，补件后回待受理，并尝试跨单访问本人详情。
- 本地走查二。同一工单走值班受理、主责派单、商户协办、承办送审、管理方退回再发布；核对代接、跨商户及直接结案拒绝。再走三项评价、重复提交、确认解决、原单补办批准或驳回。
- 微信与平台走查。使用平台实际回执和体验版，在另一账号真机扫码核对公开字段；本人私下核验后查看结果。验证回执超时续取、图片和发布后的通知。无订阅授权或通知失败时，仍可在 T04 查看已发布反馈。
